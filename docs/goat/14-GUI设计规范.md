# GUI 设计规范

> 统一视觉标准，新页面按此规范开发。  
> 未覆盖的细节参考已有页面的实现。

---

## 全局配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 最深背景 | `#0a0f1a` | 侧边栏、标题栏 |
| 主背景 | `#0f172a` | 窗口背景、内容区 |
| 卡片背景 | `#1e293b` | 输入框、按钮、分组 |
| 边框 | `#334155` | 输入框边框、分割线 |
| 主文字 | `#e2e8f0` | 标题、正文 |
| 次要文字 | `#94a3b8` | 描述、提示 |
| 弱文字 | `#64748b` | 页尾、占位符 |
| 强调色 | `#60a5fa` | 焦点边框、选中态 |
| 主按钮 | `#2563eb` | 保存、确认 |
| 成功 | `#4ade80` | 保存成功、连接成功 |
| 警告 | `#fbbf24` | 进行中、编辑模式 |
| 危险 | `#f87171` | 失败、删除 |

## 组别颜色

| 组 | 色值 | 用于 |
|----|------|------|
| 1 | `#60a5fa` | 边框、badge |
| 2 | `#4ade80` | 边框、badge |
| 3 | `#fbbf24` | 边框、badge |

---

## 字体

- 系统字体：`"Segoe UI", "Microsoft YaHei", sans-serif`
- 等宽字体：`"Consolas", "Cascadia Code", monospace`（快捷键）
- 大标题：26px / 700
- 页面标题：22px / 700
- 正文：13px
- 小字提示：12px
- 状态栏：12px

---

## 间距与圆角

- 页面内边距：32px
- 卡片内边距：14-16px
- 组件间距：12-16px
- 输入框圆角：8px
- 卡片圆角：12px
- 窗口圆角：10px
- 按钮圆角：8px

---

## 组件规格

### 按钮

| 类型 | 背景 | 文字色 | 边框 | 字号 |
|------|------|--------|------|------|
| primaryButton | `#2563eb` | white | none | 13px/700 |
| secondaryButton | `#1e293b` | `#94a3b8` | `#334155` | 13px/600 |
| titleBarButton | transparent | `#94a3b8` | none | 14px/700 |
| titleBarCloseButton | transparent | `#94a3b8` | none | 14px/700 |
| navButton | transparent | `#94a3b8` | none | 13px/500 |

### 导航按钮

- 高：44px
- 选中态：背景 `#1e293b` + 文字 `#60a5fa` + 600
- hover：背景 `#1e293b` + 文字 `#e2e8f0`

### 输入框

- 背景 `#1e293b` / 文字 `#e2e8f0` / 边框 `#334155`
- 圆角 8px / 内边距 7px 12px / 字号 13px
- focus 边框变为 `#60a5fa`

### 下拉框

- 同输入框样式
- 下拉菜单背景 `#1e293b`
- 选中项背景 `#334155`
