# 2026-06-30 开发记录

## POC 5：Pro 可见会话交接 → Flash 快速翻译

### 目的

验证一次 Pro 深度思考启动后，仅保存其最终可见 `content` 并按原始
`assistant` 角色回放，能否稳定提升后续 Flash 翻译。POC 不保存、回放
`reasoning_content`，也不使用检索、占位符、模糊匹配、检查或修复链。

### 实验设计

- 数据集：24 个案例，完整 200 条引用/术语包
- 重复次数：2
- `DIRECT`：完整规则包和 OCR 直接交给 Flash
- `NEUTRAL_SESSION`：相同规则包 + 普通确认消息 + OCR
- `PRO_SESSION`：相同规则包 + Pro 最终可见交接消息 + OCR
- 调用：1 次 `deepseek-v4-pro`，144 次 `deepseek-v4-flash`
- Flash 均为 `thinking: disabled`
- 三组除会话角色及 assistant 可见消息外使用相同规则和测试数据

### 原始数据

- 结果：`poc/results/session-replay-20260630-143244.jsonl`
- 可见会话：`poc/results/session-replay-transcript-20260630-143244.json`
- 盲评表：`poc/results/session-replay-blind-20260630-143244.jsonl`
- 请求完成：144/144，错误 0，空输出 0
- Pro 启动耗时：65.659 秒
- Pro 用量：12,263 prompt + 2,460 completion = 14,723 tokens，其中 reasoning 1,988
- Pro 最终可见交接：629 字符
- 持久化会话中 `reasoning_content` 字段数：0

按同一案例、同一重复次数配对比较 Pro 与 Direct：

- 两组都通过：28
- Pro 通过、Direct 失败：5
- Direct 通过、Pro 失败：3
- 两组都失败：12

因此 Pro 相对 Direct 的硬约束净提升只有 2/48，样本不足以证明稳定优势。

### 当前能确认的结论

1. 实验执行有效：模型名、thinking 开关、三组请求数、会话角色和无思维链持久化均符合设计。
2. Pro 可见交接明显减少了双空格错误，并略微提高重复稳定性。
3. Pro 同时造成更多术语遗漏；其硬约束总通过率只比 Direct 高 4.2 个百分点，未形成明确优势。
4. 抽查语义案例没有发现 Pro 稳定领先：部分句子更完整，另一些更生硬或出现数量表达错误。
5. 这次 Pro 最终可见内容主要是在复述规则，尚未形成高价值、可复用的任务记忆；这可能是效果有限的重要原因。
6. 盲评表的语义忠实度和约束下自然度仍为空，当前不能宣称整体翻译质量胜负。

### 下一步

先完成隐藏组别和重复次数的盲评，再按硬约束门控汇总语义忠实度与自然度。
只有盲评也显示 `PRO_SESSION` 无稳定优势时，才判定“单次 Pro 可见规则交接”不足以实现目标，
并转向让 Pro 生成更具体的可执行记忆/示例，或对实际 OCR 任务进行按需规划，而不是继续增加同类规则复述。
