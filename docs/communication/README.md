# AI 协作记录

## 📋 文档说明

本目录存放 AI 之间的**对接文档**，用于技术交流和知识传递。

**重要**：这里只保留**当前需要讨论的问题**，历史记录移到 `docs/history/`。

```
01-交接文档.md    — 给下一位架构师 AI 的项目概览（当前状态）
02-dp对话.md      — 技术专家 AI 对当前问题的深度分析
03-op对话.md      — 项目方对专家反馈的回应和决策
04-cd对话.md      — CD（持续部署）对话
05-qoder对话.md   — QoderWork 协作记录（当前进度与未解决问题）
```

## 🔄 工作流程

1. **执行 AI** 发现问题 → 写入 `02-专家反馈.md`
2. **项目方** 阅读 → 在 `03-审查回应.md` 中决策（采纳/拒绝）
3. **执行 AI** 根据决策实施
4. 问题解决后 → 归档到 `docs/history/YYYY/MM/DD.md`
5. `02-专家反馈.md` 清空，准备下一个问题

---

## ✍️ 文档规范

### 执行 AI 规则
1. ❌ **不在 communication 中累积历史** - 问题解决后立即归档到 history
2. ✅ **只保留当前讨论的问题** - 02-专家反馈.md 同时只有 1 个问题
3. ✅ **完成报告写入 history** - `docs/history/YYYY/MM/DD.md`
4. ✅ **Bug 修复更新清单** - `docs/12-待解决问题清单.md`

### 架构师 AI 规则
1. ✅ **先读交接文档** - 了解项目当前状态
2. ✅ **发现问题写入 02** - 详细分析 + 解决方案
3. ✅ **等待项目方决策** - 读取 03-审查回应.md
4. ✅ **实施后归档** - 移到 history，清空 02
