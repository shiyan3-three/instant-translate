8.2 沉浸 ◎ — 布局不变量（代码约束）

语义: chrome off, text on（框隐字显）

chrome 含: 背景、边框、阴影、badge/标题文字的「可见绘制」
text 含: 译文/OCR 正文

不变量:
  body_text.screen_pos_after == body_text.screen_pos_before
  （开启 ◎ 后正文几何位置不得上移）

实现约束:
  - 隐藏 head/badge: 用 visibility=Hidden 或固定高度占位
  - 禁止: hide() + 去掉 head 布局 + padding 清零 导致 body 上移
  - 卡片: 背景透明、无 border、无 shadow；padding 保持与可见态相同
  - 按钮开启态: 高亮（ACCENT 底/描边），不要只用 opacity 变淡
  - 组 ◎: 隐藏 selection 轮廓 + 两卡 chrome + corner bars；字仍在

伪代码:
  def set_body_immersive(card, on: bool):
      card.setProperty("immersive", on)
      card.style().unpolish(card); card.style().polish(card)
      head.setVisible(True)           # 仍占位
      head.setAttribute(Qt.WA_TransparentForMouseEvents, on)
      # 或 head 保持 sizeHint，用 palette/opacity 画成全透明
      if on:
          assert card.body_geometry_global() == before
