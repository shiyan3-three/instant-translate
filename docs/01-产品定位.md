# 产品定位

## 一句话定位

一个面向学习和文字内容场景的 Windows 即时辅助翻译悬浮工具。

## 目标用户

本项目服务的不是所有需要翻译的人，而是以下几类用户：

- 在直播课、录播课、公开课中遇到外语字幕或题目时，需要快速辅助理解的人
- 在做翻译题、外语阅读、桌面学习任务时，希望局部查看翻译结果的人
- 在文字游戏、跑团、视觉小说、国外游戏中，希望不打断当前窗口就能辅助理解文本的人

## 核心价值

### 1. 不切窗口

翻译能力应附着在当前任务上，而不是把用户从当前界面带走。

### 2. 不打断节奏

用户不是在“使用翻译器”，而是在“做一件自己的事时，顺手看一眼翻译”。

### 3. 低干扰

平时只显示必要边框和翻译结果，控制按钮只在编辑模式下暴露。

### 4. AI 作为能力增强，而不是产品主体

AI 的职责是把 OCR 提取出的文本快速翻译出来，而不是替代整个交互系统。

## 典型场景

## 场景一：直播课辅助

用户正在看直播课，老师给出一段英语或日语材料。用户来不及独立翻译，想快速确认其中一两句的意思，但又不想切走播放器或直播窗口。

## 场景二：翻译题辅助理解

用户正在做练习，先自己翻，再用工具辅助验证。这个工具的角色是“辅助理解”和“快速兜底”，不是替代思考。

## 场景三：文字游戏或跑团

用户正在运行国外游戏或含大量外文文本的程序。现有翻译软件一旦弹出或抢焦点，就会破坏沉浸感。本项目要尽量避免这种情况。

## 为什么不是通用翻译平台

本项目不打算解决所有翻译问题，原因有两个：

- 用户真正的痛点是“当前窗口内的局部即时理解”，不是完整文档翻译流程
- 范围越大，越容易牺牲速度、稳定性和低干扰体验

因此本项目只聚焦以下问题：

- 固定区域识别
- 本地 OCR
- 联网 AI 翻译
- 悬浮结果展示
- 最多 3 组独立工作流

## 与现有产品的差异方向

虽然市面上已经有 OCR 翻译、屏幕翻译、实时字幕翻译类工具，但本项目希望把差异点收得更尖：

- 更强调学习和文字内容场景
- 更强调低干扰悬浮交互
- 更强调“固定区域持续识别”而不是一次性截图
- 更强调自带 OpenAI 兼容接口配置能力
- 更强调少而精的功能边界

## 产品原则

- 不打断优先
- 低干扰优先
- 稳定优先
- 轻量优先
- 真实可用优先
